# Production improvement plan — 2026-09-18

## Verified architecture and operating boundaries

- Repository: `/home/micu/PCEP_webApp`, branch `main`, starting commit `477cfe7`.
- Existing untracked `.claude/` belongs to the operator and must be preserved.
- Public requests: Cloudflare → shared cloudflared tunnel → HTTPS loopback system Nginx → `/var/www/pcep/frontend` or `127.0.0.1:8001` → non-root Gunicorn/Python 3.12 Docker container → PostgreSQL 16 Docker container.
- Only the backend publishes a PCEP port, bound to loopback. PostgreSQL has no host port. The PCEP bridge contains these two services only. Persistent database/static/media volumes exist.
- Nginx serves separate host static/media copies and generated `/practice/`, sitemap and robots files from `/var/www/pcep/seo`. A weekly systemd timer runs `/usr/local/sbin/pcep-seo-pages`. These production additions were absent from the starting tree; the vhost and safe generator are now tracked.
- Cloudflared has a shared catch-all forwarding to `https://127.0.0.1:443`, local certificate verification disabled; ACME is forwarded to port 80, and another application has a specific route. Global Nginx real-IP configuration trusts Cloudflare ranges and loopback. UFW denies inbound HTTP/HTTPS; SSH and unrelated TURN ports are allowed. The default TLS vhost redirects unknown hosts to `https://micutu.com/`.
- TLS uses Let's Encrypt at Nginx and Cloudflare at the edge. Shared services, firewall and tunnel routes will not be reconfigured for PCEP changes.
- API started with six public JSON endpoints and no authentication oracle; database-independent liveness, answer-safe search and the daily challenge now make nine. Questions use public choice serializers; answers/explanations are returned by POST submission only. SQLite is used for local tests, PostgreSQL in CI. React owns sessions; progress remains localStorage based. Pyodide executes in a terminable worker. Workbox caches the shell and runtime, not APIs.

## Deployment and rollback strategy

Each logical stage gets a reviewed atomic commit with existing identity, no attribution and no push. Targeted tests precede commits. Live changes require backups outside the Git tree. Fix P0 generated files first without restarting services. Build/smoke backend candidate before replacing only backend (leave DB running); retain prior image and database backup. No question reset/reseed and no destructive migration. Nginx edits preserve ACME, certificates, SEO routes and shared include behavior; test configuration before graceful reload. Frontend is published only after complete validation. Verify public domain, API leakage, grading, assets/worker, headers and browser mobile flows afterward. Full baseline/final commands and known limits go into the final report.
